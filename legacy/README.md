# Versiones históricas

Esta carpeta conserva implementaciones anteriores de Splatt Elite como referencia. No forma parte de la arquitectura activa y no debe utilizarse para instalar el sistema Raspberry actual.

## `esp32/`

Contiene la versión basada en Seeed Studio XIAO ESP32S3 Sense:

- Firmware Arduino y herramientas de prueba.
- Interfaz web del prototipo.
- Modelos 3D y documentación de montaje.
- Dianas, imágenes y manuales históricos.

Se mantiene para preservar el trabajo anterior y facilitar comparaciones. El desarrollo activo está en `app/` y `raspberry/`.
