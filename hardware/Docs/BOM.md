# Lista de Materiales (BOM) - Splatt DIY

Aquí tienes la lista de los componentes de hardware necesarios para construir el entrenador de tiro Splatt DIY.

| Componente | Cantidad | Descripción / Notas | Posible Enlace de Compra |
| :--- | :---: | :--- | :--- |
| **Seeed Studio XIAO ESP32S3 Sense** | 1 | Microcontrolador principal que incluye cámara OV3660 y micrófono PDM incorporados. | [Ver en SeeedStudio](https://www.seeedstudio.com/XIAO-ESP32S3-Sense-p-5639.html) |
| **Módulo de cámara OV3660 (Montura M12)** | 1 | Módulo de cámara compatible con el XIAO para permitir el uso de lentes intercambiables con rosca M12. | - |
| **Lente M12 de 25 mm** | 1 | Lente con distancia focal de 25 mm para conseguir el zoom y enfoque necesarios a la distancia de tiro. | - |
| **Módulo Láser** | 1 | Láser visible o Infrarrojo (IR), normalmente de 5V o 3V, para montar en tu pistola o carabina. | *[Busca "Láser módulo" en tu tienda local]* |
| **Tornillos M3x10** | 4 | Para ensamblar la carcasa impresa en 3D. | - |
| **Batería Lipo** (Opcional) | 1 | Batería de 3.7V de tamaño reducido (ej. 400mAh o 500mAh) si deseas que sea totalmente inalámbrico. | - |
| **Interruptor Deslizante** (Opcional) | 1 | Pequeño interruptor para encender y apagar el dispositivo fácilmente. | - |

## Archivos para Impresión 3D (STL)

Puedes encontrar los diseños de la carcasa, los soportes de la cámara y otros accesorios para imprimir en 3D en la carpeta [`3D_Models`](./3D_Models).

**Recomendaciones de impresión:**
- **Material:** PLA, PETG o ABS.
- **Relleno (Infill):** 20% suele ser suficiente para la mayoría de piezas.
- **Soportes:** Depende de la orientación de cada pieza, verifica en tu software de laminado (slicer).
